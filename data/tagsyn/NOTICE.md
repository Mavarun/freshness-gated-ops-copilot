# Stack Exchange tag synonyms: attribution and licence

`stackexchange_tag_synonyms.json.gz` is a snapshot of community-approved tag
synonym pairs (tag names and applied counts only, no post text), fetched
2026-10-07 by `scripts/fetch_tag_synonyms.py` from the Stack Exchange API v2.3
(<https://api.stackexchange.com/2.3/tags/synonyms>).
